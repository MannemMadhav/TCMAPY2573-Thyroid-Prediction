Understanding Your Prediction

Learn how the hierarchical thyroid prediction system processes inputs, generates a classification, and explains model behaviour.

01

How a Prediction Is Generated

1

Input Processing

The application converts submitted clinical values into the input representation expected by the trained model.

2

Stage 1 Screening

The first model performs binary screening between Normal and Thyroid Dysfunction.

3

Stage 2 Classification

The stacking ensemble provides detailed classification among Normal, Hyperfunction, and Subnormal categories when required by the cascade.

02

Understanding Prediction Probabilities

Probability values represent the model's estimated support for its available classes. They are not the same as a confirmed clinical diagnosis or a guaranteed probability of disease.

Interpret these values alongside the predicted category, the model's limitations, and advice from a qualified healthcare professional.

03

Understanding SHAP Explanations

SHAP helps explain how input features contribute to a particular model output relative to the explainer's reference or baseline.

Important distinction

A feature's contribution describes model behaviour. It does not prove that the feature caused a thyroid condition.
